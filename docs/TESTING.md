# JSON Viewer 功能测试清单

## 发现的 Bug（已修复）

### ✅ 已修复（提交 9de772f）

1. **路径生成错误**：顶层键的路径被错误设置为 `$` 而不是 `$.key`
   - 影响：点击树节点无法正确显示路径

2. **数组元素显示错误**：数组元素显示 `0: value` 而不是 `[0]: value`
   - 影响：UI 显示不一致

3. **路径解析不支持括号表示法**：`getValueByPath` 无法解析 `$.hobbies.[0]`
   - 影响：点击树形视图中的数组节点无法正确显示值

## 布局问题（已修复）

### ✅ 已修复
1. **Flex 高度链问题**（提交 1a3b137）：
   - `height: 100%` 在 flex 子元素中不生效
   - 替换为 `display: flex; flex: 1; minHeight: 0`

2. **全部展开后菜单栏消失**（提交 fbdc89d）：
   - 树形区域缺少 `minHeight: 0`
   - flex 子元素默认 `min-height: auto` 防止收缩
